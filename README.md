# Syntecxhub_Sales_Analyzer
Sales Analytics (Project 1) — monthly/quarterly line charts (Pandas resample) + ranked bar &amp; capped pie (groupby, top5+Other). Auto-detects Date/Category/Sales_Amount for any CSV, exports 300 DPI PNGs (sales_trends, category_comparison, market_share) + summary (total/top/best quarter) in Tkinter multi-tab app.
